# One Dimensional Cellular Automata: Application of Evolutionary Systems for Sea Level Analysis

This repository refers to the final project of the course Mathematical-Computational Modeling Applied to Epidemiology, offered at UFRPE by Professor Jones Alburqueque.

The aim of the study is to analyze sea level variability as a natural phenomenon, aggravated by external variables. The complexity of these interactions will be investigated through the study of autonomous cells, which provide a simple representation for complex and dynamic systems.

Project developed by Raquel Santos, Information Systems student, 2025.
